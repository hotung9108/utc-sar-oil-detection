# WEB WORKSTATION — SAR OIL SPILL DETECTION

Thư mục chứa toàn bộ mã nguồn giao diện Web tương tác Streamlit phục vụ quan trắc vết dầu tràn trên ảnh SAR Sentinel-1.

### Khởi động nhanh:
- **Windows (1-click):** Chạy file `run_web.bat`
- **Dòng lệnh (từ thư mục gốc):** `python -m streamlit run web/app.py`
- **Dòng lệnh (từ thư mục `web/`):** `python -m streamlit run app.py`
